# Tandemloop Screening Test Solutions
Author: Hemanth Sai Kovuru  
Language: Python

## Overview
This repository contains solutions for the Tandemloop Screening Test.

---

## Problem Files

### Problem-1.py
A simple calculator using a class that performs:
- Addition
- Subtraction
- Multiplication
- Division

### Problem-2.py
Generates the first 'a' odd numbers.

### Problem-3.py
Generates all odd numbers up to the nearest odd number ≤ input.

### Problem-4.py
Counts how many numbers in a list are divisible by each number from 1 to 9.

---

## How to Run
Run each file using:

python Problem-1.py  
python Problem-2.py  
python Problem-3.py  
python Problem-4.py  

---

## Notes
- All programs use Python 3
- No external packages used
